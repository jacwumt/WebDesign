# Component Library

Separate from Assignment folders. This starter library contains the reusable shared header/nav, skip link, button and footer patterns adapted from Assignment6, plus the Assignment7 Flexbox introduction and Grid activity cards.

- `index.html`: workspace for trying variations.
- `components.html`: finished examples.
- `styles/styles.css`: component rules and responsive behavior.
- `images/`: example content.

Copy a component's HTML and ALL its CSS rules into a project; replace its content and links. A project's stylesheet does not link back here. Use descriptive variant names such as `.community-intro-bordered` when experimenting.
