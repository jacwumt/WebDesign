# Assignment 4 - Visual Appeal, Structure, & Organization

## Visual Appeal

I used six simple icons for the rod, line, fly, fish, mountain stream, and landing net. I used them together in the gallery so they work as a matching set instead of random images.

I kept the same blue, gray, and white color palette from my earlier pages because I wanted the site to stay consistent. I also kept simple borders and rectangular shapes because they fit the clean and basic idea of tenkara fishing.

I used **Roboto Slab** for headings and **Open Sans** for regular text. Roboto Slab gives the headings a little more character, while Open Sans is easy to read for paragraphs, tables, and forms.

## Structure & Organization

The table organizes the main pieces of tenkara gear, what each item does, and a simple example of what a beginner might use. A table works well because the information is easier to compare in rows and columns than in several paragraphs.

For the form I used labels above each field, a simple vertical layout, matching borders, and the same site colors. I kept the form narrow enough that it is easy to scan and fill out.

## Design Goals

The goal of the form is to let a visitor ask a beginner tenkara question. That supports the site's overall goal of introducing people to tenkara and basic gear.

The gallery supports the same goal by giving visitors a quick visual overview of important parts of tenkara fishing. It also lets me use the six icons as a consistent visual set.

The gallery uses a uniform pattern. Each icon is shown in the same kind of box with the same spacing, size, and label placement. I chose a uniform pattern because the icons are all equally important.

## Checking In

I think hierarchy and alignment are getting easier to understand because I can see how headings, spacing, and repeated edges make the pages easier to follow. The two Google Fonts helped me understand how typography can separate headings from normal text without making the site too complicated.

The component page is useful because it keeps copies of the navigation, gallery, table, and form in one place. I also used `display: flex` for the icon gallery. Flexbox made it easier to keep the icons in rows while still allowing them to wrap on a smaller screen.
